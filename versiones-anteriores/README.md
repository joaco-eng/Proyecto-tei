# Versiones anteriores del proyecto

Esta carpeta conserva el código utilizado en las primeras etapas del proyecto, cuando la ESP32 funcionaba como servidor web local.

Estos archivos se mantienen como registro de las iteraciones realizadas. La versión final utiliza WiFi, Railway y PostgreSQL para transmitir, almacenar y visualizar las mediciones.

Para consultar el funcionamiento actual, revisar [Software](../software/README.md).
